## 🥇 Эшелон 1: Твоё обязательное ядро (Учить и писать руками)

### 1. 🐍 Python — Главный язык кибербезопасности и ИИ (Приоритет №1)
- **Зачем нужен:**
  - **Offensive / AppSec:** написание эксплойтов, автоматизация запросов к API, обход фильтров, парсинг данных, фаззинг.
  - **Defensive / SOC:** парсинг гигабайтных логов, обогащение индикаторов компрометации (IoC) через VirusTotal/AbuseIPDB API, автоматизация реагирования (SOAR).
  - **AI/ML Security:** 99% всего машинного обучения (PyTorch, Hugging Face, Ollama, LangChain) и инструментов взлома/защиты ИИ (Garak, PyRIT, IBM ART, ModelScan) написано на Python.
- **Насколько глубоко учить:** уметь с нуля написать скрипт на 50–150 строк (функции, словари, `requests`, файлы, `json`, `re`, базовые классы).

```python
# Пример: найти в JSON-логе API все запросы со статусом 403/500 и подозрительным промптом
import json

with open("api_events.jsonl", encoding="utf-8") as f:
    for line in f:
        event = json.loads(line)
        if event["status"] in (403, 500) or "ignore previous" in event.get("prompt", "").lower():
            print(f"[ALERT] User={event['user_id']} IP={event['ip']} Status={event['status']}")
```

### 2. 🐧 Bash (Linux) + 🪟 PowerShell (Windows) — Языки операционных систем (Приоритет №2)
- **Зачем нужны:**
  - **Bash:** почти все серверы, контейнеры Docker и облачные кластеры работают на Linux. В Bash ты соединяешь системные утилиты (`grep`, `find`, `awk`, `curl`, `ss`) в быстрые однострочники.
  - **PowerShell:** более 80% корпоративных компьютеров сотрудников и контроллеров домена (**Active Directory**) работают на Windows. И атакующий при пост-эксплуатации, и SOC-аналитик при расследовании инцидента на Windows используют PowerShell.
- **Насколько глубоко учить:** уверенные однострочники, конвейеры (`|`), циклы `for`, переменные и чтение чужих скриптов.

```bash
# Bash (Linux): найти топ-5 IP, которые чаще всего получали ошибку входа по SSH
grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head -n 5
```

```powershell
# PowerShell (Windows): показать последние 10 неудачных попыток входа в Windows (Event ID 4625)
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625} -MaxEvents 10 |
    Select-Object TimeCreated, Message
```

### 3. 🗄️ SQL — Язык баз данных (Приоритет №3)
- **Зачем нужен:**
  - **Red Team / AppSec:** невозможно по-настоящему понимать уязвимость **SQL Injection (SQLi)** и атаки на ИИ-агентов с функцией `Text-to-SQL`, если ты не понимаешь, как работают `SELECT`, `WHERE`, `UNION`, `JOIN` и комментарии `--`.
  - **Blue Team / GRC / Аналитика (как в курсе Google Cybersecurity):** выгрузка данных о доступах сотрудников (IAM), аудит ролей и поиск аномальных транзакций в реляционных базах и облачных хранилищах.
- **Насколько глубоко учить:** `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `INNER/LEFT JOIN`, `UNION`, параметризованные запросы. (Учится за 3–4 вечера!).

```sql
-- 1. Как выглядит запрос аналитика безопасности (Blue Team):
-- Найти пользователей, которые заходили с 3 и более разных стран за последние сутки
SELECT user_id, COUNT(DISTINCT country) AS countries_count
FROM login_audit
WHERE login_time >= NOW() - INTERVAL '24 hours'
GROUP BY user_id
HAVING COUNT(DISTINCT country) >= 3;

-- 2. Почему опасна склейка строк (Red Team — SQL Injection):
-- Опасный код:  "SELECT * FROM users WHERE username = '" + user_input + "'"
-- Ввод хакера:  admin' OR 1=1 --
-- Итог в БД:    SELECT * FROM users WHERE username = 'admin' OR 1=1 --'
```

## 🥈 Эшелон 2: Уметь читать и понимать (Во время Фазы 3)

### 4. 🌐 JavaScript / TypeScript (+ HTML) — Язык браузера и веб-фронтенда
- **Зачем нужен:**
  - Браузер понимает **только** JavaScript. Поэтому любая атака **XSS (Cross-Site Scripting)**, кража токенов из `localStorage`, эксплуатация кривого **CORS** или `postMessage` пишется на JavaScript.
  - Огромное количество современных **ИИ-агентов, расширений VS Code и MCP-серверов** пишется на TypeScript / Node.js.
  - В Bug Bounty и пентесте чтение клиентских `.js`-файлов сайта (вкладка *Sources / Debugger* в браузере) позволяет находить скрытые эндпоинты API (`/api/v1/internal/admin`), зашитые ключи и логические ошибки.
- **Насколько глубоко учить:** тебе **не нужно** учить React или верстать сайты! Нужно понимать синтаксис, `fetch()`, `document.cookie`, `localStorage`, `innerHTML` vs `textContent` и уметь прочитать 30 строк чужого JS-кода.

```javascript
// Что нужно понимать в JavaScript безопаснику:
// 1. ОПАСНО (DOM XSS — вставляет сырой HTML и выполняет скрипты):
element.innerHTML = untrustedLLMResponse;

// 2. БЕЗОПАСНО (вставляет только чистый текст, теги <script> не выполняются):
element.textContent = untrustedLLMResponse;
```

### 5. 🔍 Языки запросов SIEM (KQL / SPL), RegEx и YAML
- **Зачем нужны:**
  - **RegEx (Регулярные выражения):** поиск сложных шаблонов в тексте (API-ключей, номеров карт, IP-адресов, промпт-инъекций).
  - **KQL (Kusto Query Language)** и **SPL (Splunk Processing Language):** языки поисковых запросов в главных корпоративных SIEM-системах мира (Microsoft Sentinel / Defender и Splunk). Очень похожи на SQL и конвейеры Linux!
  - **YAML и JSON:** языки конфигураций (Docker Compose, GitHub Actions, правила детекции **Sigma**, шаблоны сканера **Nuclei**, настройки **Promptfoo** и **Garak**).

```kql
// Пример KQL (Microsoft Sentinel / Defender):
// Найти подозрительные запуски PowerShell со скрытым/закодированным окном за последние 24 часа
DeviceProcessEvents
| where Timestamp > ago(24h)
| where FileName =~ "powershell.exe"
| where ProcessCommandLine has_any ("-enc", "-EncodedCommand", "Hidden", "DownloadString")
| project Timestamp, DeviceName, AccountName, ProcessCommandLine
```

## 🥉 Эшелон 3: Специализированные языки (НЕ трогай в первый год!)

| Язык | Когда он действительно понадобится | Почему НЕ надо учить его прямо сейчас |
| :--- | :--- | :--- |
| **Go (Golang)** | Если ты захочешь писать свои сверхбыстрые сетевые сканеры или глубже уйти в безопасность облаков (Docker, Kubernetes, Terraform написаны на Go). | Для старта и для AI Security Python в 10 раз важнее и богаче библиотеками. |
| **C / C++** | Если ты пойдёшь в **Binary Exploitation** (переполнение буфера в памяти), поиск уязвимостей в ядре ОС или разработку антивирусных движков. | В веб-хакинге, API, облаках, GRC, SOC и AI/LLM Security памятью управляет среда выполнения — C/C++ там не используется. |
| **Assembly (x86/ARM)** | Только для **Reverse Engineering** (вскрытия скомпилированных вирусов `.exe`/`.elf` в Ghidra или IDA Pro без исходного кода). | Самый высокий порог входа; не нужен для 90% вакансий в кибербезопасности. |
| **PHP / Java / C#** | При аудитах исходного кода (SAST / White-Box AppSec) старых корпоративных веб-приложений. | Когда ты знаешь Python и JavaScript, ты сможешь **прочитать** кусок кода на PHP или Java с помощью документации или LLM за 5 минут. |

## 🗺️ Пошаговый план: в каком порядке осваивать языки в нашем проекте

1. **Месяц 1–2 (Фаза 1):** **Bash** (команды терминала, конвейеры `|`, 3 простых скрипта).
2. **Месяц 2–4 (Фаза 2):** **Python** (основы, словари/JSON, `requests`, `re` — регулярные выражения, 4 проекта).
3. **Месяц 5–6 (Фаза 3):** **SQL** (базовые запросы и понимание SQLi — 1 неделя) + **чтение JavaScript** (DOM, `fetch`, XSS — 1 неделя).
4. **Месяц 7–12 (Фазы 4–5):** **Углублённый Python для AI Security** (PyTorch, NumPy, Ollama API, Garak, PyRIT) + **YAML/JSON** для настройки сканеров и правил.
