# 🎮 Лаборатория: Интерактивный Тренажёр Python для Security

Добро пожаловать в персональный тренировочный полигон по программированию на Python!

---

## 📂 Файлы в этой папке:
- **`practice.py`** — интерактивный тренажёр из 5 уровней с автопроверкой.

---

## 🎯 Уровни испытаний:
1. **🟢 Уровень 1:** Досье исследователя (переменные, типы данных).
2. **🟡 Уровень 2:** Детектор сетевых портов (`if / elif / else`).
3. **🟠 Уровень 3:** Сканер открытых портов (списки, циклы `for`).
4. **🔴 Уровень 4:** Валидатор надёжности паролей.
5. **🟣 Уровень 5 (AI Security):** Защитный фильтр от Prompt Injection.

---

## 🚀 Как запускать:
1. Открой файл **`practice.py`** в VSCodium.
2. Пиши свой код в блоках с заданиями.
3. Нажимай **▶ Play** в правом верхнем углу, чтобы проверить свои решения.
