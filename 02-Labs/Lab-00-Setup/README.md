Добро пожаловать в твою первую лабораторную папку!

## Что будет лежать в папке `02-Labs/`:
Для каждой практической работы мы будем создавать отдельную подпапку (`Lab-01-FGSM`, `Lab-02-Pickle-Exploit`, `Lab-03-Prompt-Injection` и т.д.), внутри которой будут:
1. `README.md` — описание задачи, теория простыми словами и выводы.
2. Код на Python (`.py` или Jupyter Notebook `.ipynb`).
3. Сгенерированные картинки/графики (с копией в `05-Assets/`).
