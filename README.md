## 📂 Структура проекта

Все наши файлы, код, фото и материалы разложены по чёткой системе, чтобы ничего не терялось на протяжении всего курса:

```text
Security/
├── 00-Roadmap/        # План обучения, трекер прогресса и профиль коллеги
├── 01-Theory-Notes/   # Конспекты по модулям, разборы статей, шпаргалки
├── 02-Labs/           # Практические лабораторные работы, Jupyter-ноутбуки и эксплойты
├── 03-Datasets-Models/# Датасеты, веса моделей и тестовые сэмплы (тяжелые файлы в .gitignore)
├── 04-Resources/      # Статьи (PDF), полезные ссылки, YouTube-плейлисты, книги, инструменты
├── 05-Assets/         # Скриншоты, схемы архитектур, графики, фото и медиа-материалы
└── 06-Projects/       # Твои собственные пет-проекты, CTF-решения и портфолио
```

## 🛠️ Как мы работаем с Git и GitHub
1. Все конспекты и код мы пишем здесь и фиксируем через `git commit`.
2. Тяжелые файлы (большие модели `.pt`, `.bin`, `.onnx` и огромные датасеты) автоматически игнорируются файлом `.gitignore`, чтобы репозиторий оставался быстрым и чисто загружался на GitHub.
3. По итогам каждого модуля мы обновляем трекер прогресса в `00-Roadmap/CURRICULUM.md`.
